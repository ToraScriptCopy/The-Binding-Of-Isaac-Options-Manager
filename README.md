# **Isaac Options Manager**

A simple and lightweight utility to quickly modify the options.ini file for **The Binding of Isaac: Rebirth** (and its DLCs). Forget about manually navigating through your file explorer to tweak your game settings.

## **Features**

* **Quick Editing:** Modify your graphical and gameplay settings directly from the app.  
* **One-Click Save:** Apply your changes instantly to options.ini.  
* **User-Friendly:** No more hunting through Documents/My Games/Binding of Isaac... folders.

## **Usage**

1. Download and launch the application.  
2. Adjust your desired settings in the interface.  


##  **Security & VirusTotal**

Some antivirus software may flag this application as a "threat." This is a **false positive**.

* [**Check VirusTotal Report**](https://www.virustotal.com/gui/file/170436a2b684bf3a4fd0d62d9b323547746302558e94c6ad04d37cd59c34f2aa?nocache=1)

**Why are there detections?**

The program requires **Administrator privileges** to modify game files located in your system directories. Because it performs write operations on configuration files, some heuristic engines may flag it as suspicious. This is completely normal behavior for a file-manager utility.
